# on the low

ひっそりとした秘密基地。ローポリと低い音でできた、ももいもいみの隠れ家のWebサイト。

## フロア

- `index.html`：B1 入口。岩に隠れたももいもいみと、基地ラジオ
- `music.html`：B2 音源ルーム。作者の曲と基地テープ
- `explore.html`：B3 探検。基地の奥で、隠されたものを探す

くわしい仕様、ファイルの役割、曲や3Dモデルの足しかたは [docs/concept.md](docs/concept.md) にまとめています（B3のネタバレあり）。

## 見かた

ブラウザで `index.html` を開けば、そのまま見られます。3D（Three.js）とフォントはネットから読み込むので、オンラインで開いてください。Blenderのモデル（`models/momoimoimi.glb`）は、ローカルサーバーか GitHub Pages で開いたときだけ読みこまれます。
