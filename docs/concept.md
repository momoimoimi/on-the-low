# on the low コンセプトと仕様

サイトを作りこむときの決めごとをまとめたメモ。作業を始める前に読んで、決めたことが増えたらここに書き足す。

## ブランド

- **名前**：on the low（小文字で書く）
- **感じ**：ひっそりとした秘密基地。こっそり、ひっそり。全部を見せず、見ようとした人にだけ見える
- **テーマ**：ローポリ × 作者の音楽
- **舞台**：地下へ降りていく秘密基地。夜。サイトのページはフロアになっている

| フロア | ページ | 中身 |
|---|---|---|
| B1 入口 | `index.html` | 岩に隠れたももいもいみ、住人ファイル、基地ラジオ |
| B2 音源ルーム | `music.html` | 作者の曲と基地テープの棚、音に反応する部屋 |
| B3 探検 | `explore.html` | 洞くつの部屋をめぐって、隠されたものを探す |

## キャラクター：ももいもいみ

- 読み：MOMOIMOIMI。住人 No.001
- 桃のかたちのローポリのキャラ。いつもヘッドホンをしている
- 頭に茎と葉っぱ、ほっぺ、小さな足
- 好きなもの：ローポリ、低い音、夜ふかし
- 特技：低音で床をちょっとだけ揺らす
- 地上ではほとんど見かけない。昼は基地で寝ていて、夜になるとクリスタルを鳴らしながらビートを組む
- サイトのプロフィール文は仮。設定が決まったら書きかえる

## 見た目

- 背景は暗い夜の色のまま（ライト／ダークの切りかえはしない）
- 色は `css/style.css` の `:root` でまとめて管理

| 名前 | 色 | 使いどころ |
|---|---|---|
| `--night` | #15121f | 基地の壁、背景 |
| `--cave` | #221d33 | カードなど一段上の面 |
| `--rock` | #3a3254 | 線、オフのマス |
| `--fog` | #ece6f6 | 文字 |
| `--dim` | #a59cbc | 補足の文字 |
| `--momo` | #ff9f8c | 桃色。ももいもいみ、メロディ、ボタン |
| `--glow` | #9d8cff | クリスタルのラベンダー、ドラム |
| `--moss` | #6fd6b8 | 葉っぱ、「在室中」「ON AIR」 |

- フォント：見出しは Dela Gothic One、本文は Zen Kaku Gothic New、ラベルや数字は DM Mono
- 3Dは全部フラットシェーディングで、面の角が見えるローポリにする

## トップの3Dシーン（`js/scene.js`）

- Three.js r128 を CDN から読み込む
- すり鉢状の地面、まわりの岩、クリスタル5本、ランタン、ホタル
- **ももいもいみは、カメラの前の大きな岩のうしろに隠れている**。これはわざと。普段は見えない
  - パソコン：トップの上でマウスを左右に動かすと、カメラが岩の横に回りこんで見える。マウスを外すと戻る
  - スマホ：3Dの左右をタップすると、そっち側からのぞける。3.5秒で戻る
  - 10秒前後に一回、自分から岩の横にこっそり顔を出して、すぐ引っこむ
  - ラジオが鳴っているあいだは、つられて少しだけ出てくる
  - 右上に「← のぞいてみて →」のヒント
- まわりの岩は、カメラの手前側には置かない（隠すのは決まった岩だけ）
- 住人ファイルのポリゴン数は、3Dモデルから実際に数えた値を出している

## 基地ラジオ（`js/radio.js`）

- 16ステップのシーケンサー。上の5段がメロディ（Eマイナーペンタトニック：D5、B4、A4、G4、E4）、下の3段がドラム（HAT、SNARE、KICK）
- 音はファイルを使わず、Web Audio でその場で合成する。ローファイ寄りで、少しスウィングとテープの揺れを入れている
- BPM は 66〜104（最初は 82）。「おまかせ」「クリア」ボタンあり
- 音が鳴るたびに `radio:step` イベントを出し、3Dシーンがそれを受けて、キックで跳ね、メロディでクリスタルが光る
- 音は「再生」を押してから鳴る
- 音のしくみ（ドラム、キー、シーケンサー）は `js/synth.js` にまとめてあり、全ページで共通

## B2 音源ルーム（`music.html`、`js/music.js`）

- 上に3Dの部屋。スピーカーの横でももいもいみが音を聴いていて、宙に浮いた「音の石」が、鳴っている音に合わせて面が割れるように広がる
- 棚が2つ
  - **作者の曲**：`music/tracks.js` に書いた曲が並ぶ。曲がないあいだは「録音中…」のテープが3本
  - **基地テープ**：ももいもいみが録った設定のビート。Web Audio でその場で鳴らす（B3の夜／クリスタル通り／ひっそり）。2パターンを交互にくり返す
- 鍵つきのテープ「？？？」が1本あり、B3でひみつのテープを見つけると「ひみつのテープ」として聴けるようになる

### 作者の曲の足しかた

1. mp3 を `music/` フォルダに置く
2. `music/tracks.js` に1行足す：`{ title: '曲名', file: 'music/ファイル名.mp3', note: 'ひとこと' },`

## B3 探検（`explore.html`、`js/explore.js`）

※ここから先はネタバレ

- カメラのまわりに部屋がぐるっと並んでいて、← → で向きを変える：入口の通路、クリスタル洞、ラジオブース、ももいもいみの寝床、隠し部屋
- 隠されたものは6つ。マウスを近づけると光り、ときどき一瞬きらっとする。見つけたものはブラウザ（localStorage の `otl-found`）に記録する
  - 通路のメモ：通路の岩の下
  - 落ちていた葉っぱ：寝床の床
  - ラジオのメモ：ラジオブースの棚の上。クリスタルの合言葉のヒントが書いてある
  - かくれんぼ中のももいもいみ：通路の岩、ラジオ、ベッドのどれかのうしろ。開くたびに変わる。ときどき頭が出る
  - クリスタルの合言葉：クリスタルを E → G → A → B の順に鳴らす（B1のラジオが最初に鳴らす4音）。隠し部屋をふさいでいる岩が転がってどく
  - ひみつのテープ：隠し部屋の台の上。B2の棚に並ぶ
- ラジオブースのラジオを押すと、B1のラジオと同じビートが流れて、クリスタルも光る
- 岩やベッドのうしろにあるものは、手前のものにさえぎられて押せない（ちゃんと隠れる）

## ももいもいみの3Dモデル（`js/momo.js`）

- いまは、コードで組んだ仮のローポリモデル
- Blender で作ったモデルを `models/momoimoimi.glb`（glTF バイナリ）に置くと、全ページで自動でそれに差しかわる
  - 高さは自動で合わせる。色はマテリアルの色でOK。面はフラットシェーディングにする
  - ファイルを直接ダブルクリックで開いたときは読みこめないので仮モデルのまま。ローカルサーバーか GitHub Pages で見ると差しかわる
- 住人ファイルのポリゴン数は、そのとき表示しているモデルから数える
- `models/momoimoimi.glb` は作者が作業中。作りかけの版が一度コミットされていて、それはそのままでOK。作者が「できた」と言うまで、このファイルの変更はコミットしない

## フロアのあいだのエレベーター（`js/lift.js`）

- フロアのリンクを押すと、扉が閉まって B1 → B2 → B3 と数字が進み、次のページで扉が開く
- 「動きを減らす」設定の人には出さない

## 時間で変わる基地（`js/clock.js`）

見ている人のパソコンやスマホの時計で、基地の様子が変わる。

| 時間 | 名前 | 変わること |
|---|---|---|
| 5:00〜16:59 | 昼 | ももいもいみは寝ている。B1では岩の上に「z」が浮かび、住人ファイルが「おやすみ中」。ラジオを流すと起きて顔を出す。B2ではうとうとしていて、音を流すと起きる。B3では必ずベッドのうしろで寝ている |
| 17:00〜1:59 | 夜 | ふだんどおり。住人ファイルは「在室中」 |
| 2:00〜4:59 | 深夜 | クリスタルがいつも少し光っている。B2の棚に「午前3時のテープ」があらわれる。住人ファイルは「夜ふかし中」 |

- アドレスの最後に `?time=day`、`?time=night`、`?time=deep` をつけると、その時間の様子を確かめられる

## 音量ボタン（`js/synth.js`）

- 全ページの上のバーに、音量ボタン（大 → 小 → 消）がある。選んだ音量はブラウザに覚えておく

## ビートの共有（B1 の基地ラジオ）

- 「ビートを共有」を押すと、いまのビートとBPMが入ったリンクができてコピーされる（コピーできないときはリンクを選んだ状態で見せる）
- リンクは `index.html?beat=…&bpm=…#radio`。8段×16マスのオン・オフを16バイトにまとめて base64url で書いている
- リンクを開くと、そのビートが読みこまれて「だれかが組んだビートが届いてる」と出る

## B3 をキーボードで遊ぶ

- 洞くつの画面を Tab で選んで、↑ ↓ で部屋の中を見まわす（輪っかが出る）。Enter でしらべる。← → で部屋を移動。Esc でメモを閉じる

## 迷子ページ（`404.html`）

- ないアドレスを開いたときの「B4 そんな階はない。」ページ。岩のうしろから葉っぱがときどき出る
- どの深さのアドレスで出ても読みこめるように、GitHub Pages では `/on-the-low/` を基準にしている

## 軽さ

- 3Dは、画面に映っているときと、タブを見ているときだけ動かす（`OTL.renderLoop`）
- スマホでは描きこみの細かさ（ピクセル比）を少し下げている

## 共有したときの見た目

- タブのアイコン：`img/favicon.svg`、スマホのホーム画面用：`img/apple-touch-icon.png`
- リンクを貼ったときの画像：`img/og.png`（1200×630。岩のうしろから葉っぱだけ出ている絵）
- 共有用のアドレスは GitHub Pages の `https://momoimoimi.github.io/on-the-low/` を前提にしている。公開先が変わったら、各ページの `og:url` と `og:image` を書きかえる

## 進め方

- `v0.1` タグが最初の基準の状態。いつでもここに戻せる。`v0.2` で B2・B3 を追加。`v0.3` でスマホの手直し、共有の見た目、エレベーター、時間で変わる基地を追加。`v0.4` で軽量化、音量ボタン、迷子ページ、ビートの共有、B3のキーボード操作を追加

- 大きく変えてみたいときは別ブランチで試す。気に入ったら `main` に入れて、いまいちなら捨てる
- 区切りがついたら `v0.2`、`v0.3` とタグをつける
- サイトづくりは Claude に任されている。作者の発想を組み合わせて、Claude のセンスで進める。迷ったら作者に聞く
- `main` への push、タグの push は確認なしでどんどんやってOK
- サイトの公開（GitHub Pages など）は、完成してから作者と決める
- コミットの名前は `momoimoimi`、メールは GitHub の noreply アドレス。本物のメールアドレスはどこにも書かない
- `CLAUDE.md` と `blender/` は手元だけに置く（`.gitignore` 済み）
