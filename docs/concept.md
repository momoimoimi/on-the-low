# on the low コンセプトと仕様

サイトを作りこむときの決めごとをまとめたメモ。作業を始める前に読んで、決めたことが増えたらここに書き足す。

## ブランド

- **名前**：on the low（小文字で書く）
- **感じ**：ひっそりとした秘密基地。こっそり、ひっそり。全部を見せず、見ようとした人にだけ見える
- **テーマ**：ローポリ × 作者の音楽
- **舞台**：地下3階（B3F）の秘密基地。夜

## キャラクター：ももいもいみ

- 読み：MOMOIMOIMI。住人 No.001
- 桃のかたちのローポリのキャラ。いつもヘッドホンをしている
- 頭に茎と葉っぱ、ほっぺ、小さな足
- 好きなもの：ローポリ、低い音、夜ふかし
- 特技：低音で床をちょっとだけ揺らす
- 地上ではほとんど見かけない。昼は基地で寝ていて、夜になるとクリスタルを鳴らしながらビートを組む
- サイトのプロフィール文は仮。設定が決まったら書きかえる

## 見た目

- 背景は暗い夜の色のまま（ライト／ダークの切りかえはしない）
- 色は `css/style.css` の `:root` でまとめて管理

| 名前 | 色 | 使いどころ |
|---|---|---|
| `--night` | #15121f | 基地の壁、背景 |
| `--cave` | #221d33 | カードなど一段上の面 |
| `--rock` | #3a3254 | 線、オフのマス |
| `--fog` | #ece6f6 | 文字 |
| `--dim` | #a59cbc | 補足の文字 |
| `--momo` | #ff9f8c | 桃色。ももいもいみ、メロディ、ボタン |
| `--glow` | #9d8cff | クリスタルのラベンダー、ドラム |
| `--moss` | #6fd6b8 | 葉っぱ、「在室中」「ON AIR」 |

- フォント：見出しは Dela Gothic One、本文は Zen Kaku Gothic New、ラベルや数字は DM Mono
- 3Dは全部フラットシェーディングで、面の角が見えるローポリにする

## トップの3Dシーン（`js/scene.js`）

- Three.js r128 を CDN から読み込む
- すり鉢状の地面、まわりの岩、クリスタル5本、ランタン、ホタル
- **ももいもいみは、カメラの前の大きな岩のうしろに隠れている**。これはわざと。普段は見えない
  - パソコン：トップの上でマウスを左右に動かすと、カメラが岩の横に回りこんで見える。マウスを外すと戻る
  - スマホ：3Dの左右をタップすると、そっち側からのぞける。3.5秒で戻る
  - 10秒前後に一回、自分から岩の横にこっそり顔を出して、すぐ引っこむ
  - ラジオが鳴っているあいだは、つられて少しだけ出てくる
  - 右上に「← のぞいてみて →」のヒント
- まわりの岩は、カメラの手前側には置かない（隠すのは決まった岩だけ）
- 住人ファイルのポリゴン数は、3Dモデルから実際に数えた値を出している

## 基地ラジオ（`js/radio.js`）

- 16ステップのシーケンサー。上の5段がメロディ（Eマイナーペンタトニック：D5、B4、A4、G4、E4）、下の3段がドラム（HAT、SNARE、KICK）
- 音はファイルを使わず、Web Audio でその場で合成する。ローファイ寄りで、少しスウィングとテープの揺れを入れている
- BPM は 66〜104（最初は 82）。「おまかせ」「クリア」ボタンあり
- 音が鳴るたびに `radio:step` イベントを出し、3Dシーンがそれを受けて、キックで跳ね、メロディでクリスタルが光る
- 音は「再生」を押してから鳴る

## ファイル

```
index.html        ページの骨組み
css/style.css     色・フォント・レイアウト
js/scene.js       3Dの秘密基地とももいもいみ
js/radio.js       基地ラジオ
docs/concept.md   このメモ
```

ビルドはなし。ブラウザで `index.html` を開けば動く（3Dとフォントはネットから読み込む）。
